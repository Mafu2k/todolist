# TodoList

Aplikacja webowa do zarządzania zadaniami z rejestracją i logowaniem użytkowników.
Każdy użytkownik ma własną listę zadań. Backend w Spring Boot z uwierzytelnianiem
przez Spring Security.

## Stack

- Java + Spring Boot
- Spring Security
- Spring Data JPA + H2
- Thymeleaf

## Uruchomienie

```bash
./mvnw spring-boot:run
```

Aplikacja dostępna pod `http://localhost:8080`.
